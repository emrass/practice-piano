# Disclosure

A line that opens to show more: rarely needed settings, or an answer to "how does this work?".

- **Use** to keep a panel short. If most players need the content, show it.
- **You provide** the summary (a noun for settings, a question for help) and the body. `.disclosure-meta` on the right can say what is inside ("3 options").
- Native `<details>`; the chevron turns from right to down. Keyboard and screen readers work without script.
- Opening it pushes content down inside a scrolling panel only. Never put a disclosure on the stage.
