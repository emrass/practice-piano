# Writing

The app speaks like a good piano teacher sitting beside you: calm, specific, brief, on your side. It is read in glances between notes.

## Voice

- **Say what to do next.** "Play along with the playhead." "Start on the shown note." Not what the system is doing.
- **Name the thing.** The bar, the note, the chord, the number. "B♭: keys not together (165 ms)" beats "Some chords were uneven."
- **Stay level.** A clean run earns one word and one exclamation mark ("Clean!"). Nothing else gets one: any other pass is "Passed", and mastering an item or a tier is said as a fact ("Tier mastered."). A run that did not pass is "Nearly" or "Slow it down" ("Listen again" in ear training, which has no tempo to slow), never "Failed".
- **Speak to "you", about "your".** The app is "we" only when it listens: "We hear you."
- **No blame, no cheerleading.** "Not that one. Try again." Not "Oops!" and not "Amazing job!!"

## Mechanics

- **Sentence case** everywhere, including buttons, titles and tabs. Uppercase only through the `overline` style.
- **Buttons are verbs**: Start, Stop, Restart, Next, New exercise, Measure again. No "OK", no "Submit". A button that leads somewhere new names it: "Start sight reading", "Next: rhythm".
- **Titles are nouns or tasks**: "Piano & audio", "Connect your piano".
- **One idea per sentence.** Two short sentences instead of one joined by a dash: "Take your time. The cursor waits for you."
- **Periods** end sentences in messages and hints. Labels, buttons, titles and stats take none.
- **Length:** a practice-bar message fits two lines at 16px (about 60 characters). A hint is one sentence. A callout is two.
- **Errors** say what happened and what to do, in that order: "The browser blocked audio. Press Start once to allow it."
- **Disabled things say why**: "Off in ear training: find the notes by ear." Tooltips follow the same rules as hints: a sentence takes a period.
- American English. No emoji. No ellipsis except while something loads; a button that opens a dialog takes none ("Calibrate", "Import").

## Music in text

- Note names are capitals with the octave: C4, F♯3. Middle C is C4.
- Accidentals are ♭ and ♯, never "b" and "#". Keys are "C major", "A minor"; chords are lead-sheet symbols: Cmaj7, Dm7, G7, B♭.
- Roman numerals for function: ii7, V7, Imaj7.
- Hands are "right hand", "left hand", "both hands"; in the tightest spots RH and LH.

## Numbers

- Always with a unit and a space before it, except percent: 83 bpm, 10 ms, 1.7 s, 96%.
- Tempo is "bpm". Time is milliseconds under one second, seconds with one decimal above.
- Ranges use an en dash without spaces: C3–B4, 41–50. Changes use an arrow: 60 → 64 bpm.
- Counts read "3 of 5 passes" in a sentence and 3/5 in a table cell.
- Nothing to show yet is an en dash, not 0.
- Thousands take a comma: 12,480 XP.

## Words we use

| Use | Not |
|---|---|
| exercise | song, piece, task |
| run | attempt, try, session |
| lesson (Sight reading, Ear, Rhythm, Scales, Chords) | mode, module |
| Wait, Flow (the two practice modes) | untimed, timed |
| Today, Free practice (the two ways to practice) | guided, freestyle, play mode |
| Today's practice, the plan (what Today plays) | routine, session, workout |
| block (one lesson's part of the plan) | step, unit, task |
| level (1–100), tier (a named band of levels) | stage, rank |
| mastered | completed, done |
| due, review | overdue, repeat |
| piano | keyboard (that is the on-screen one), device |
| on-screen keyboard | virtual piano |
| computer keys | QWERTY, hotkeys |
